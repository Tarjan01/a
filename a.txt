## Plan 2：监督对比损失（SupCon）落地

### 目标

直接解决"目标域概率分布挤在 0.5 附近、特征不可分"的根因，让 neck feature 空间里正常/异常两类样本产生真实的几何间隔（margin），而不是依赖分类 loss 隐式指望特征自己分开。

### Step 1：实现 SupConLoss

新建文件 `losses/supcon_loss.py`：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SupConLoss(nn.Module):
    def __init__(self, temperature=0.1):
        super().__init__()
        self.temperature = temperature

    def forward(self, features, labels):
        """
        features: [B, D] —— 建议传入 L2 normalize 之前的原始 neck feature，函数内部会 normalize
        labels:   [B]    —— 二分类标签 (0=正常, 1=异常)
        """
        device = features.device
        features = F.normalize(features, dim=1)
        B = features.size(0)

        sim_matrix = torch.matmul(features, features.T) / self.temperature  # [B,B]

        labels = labels.contiguous().view(-1, 1)
        mask_positive = torch.eq(labels, labels.T).float().to(device)
        mask_self = torch.eye(B, device=device)
        mask_positive = mask_positive - mask_self  # 排除自身

        # 数值稳定：减去每行最大值
        sim_max, _ = torch.max(sim_matrix, dim=1, keepdim=True)
        sim_matrix = sim_matrix - sim_max.detach()

        exp_sim = torch.exp(sim_matrix) * (1 - mask_self)
        log_prob = sim_matrix - torch.log(exp_sim.sum(dim=1, keepdim=True) + 1e-8)

        mask_positive_sum = torch.clamp(mask_positive.sum(dim=1), min=1e-8)
        loss = -(mask_positive * log_prob).sum(dim=1) / mask_positive_sum

        # 过滤掉这个 batch 里没有任何正样本对的样本（该类在batch里只出现1次的情况）
        valid = (mask_positive.sum(dim=1) > 0)
        if valid.sum() == 0:
            return torch.tensor(0.0, device=device, requires_grad=True)
        return loss[valid].mean()
```

### Step 2：强制正负样本均衡采样

SupCon 要求每个 batch 里正负样本都足够多，不能用自然分布采样（目标域本身可能类别不均衡）。

新建/修改 `sk_dataset.py` 中的采样器：

```python
from torch.utils.data import WeightedRandomSampler

def make_balanced_sampler(dataset, binary_labels):
    """
    binary_labels: 数据集中每个样本的二分类标签列表 (0/1)
    确保每个 batch 里正负样本比例接近 1:1
    """
    pos_count = sum(binary_labels)
    neg_count = len(binary_labels) - pos_count
    weight_pos = 1.0 / max(pos_count, 1)
    weight_neg = 1.0 / max(neg_count, 1)
    sample_weights = [weight_pos if l == 1 else weight_neg for l in binary_labels]
    return WeightedRandomSampler(sample_weights, num_samples=len(binary_labels), replacement=True)
```

目标域 DataLoader 的 batch size 建议设为 32（保证每个 batch 至少 ~16 正 + ~16 负），如果目标域总样本数不够支撑这个 batch size 下的多样性，可以降到 24，但不要低于 16。

### Step 3：接入训练循环

修改 `DomainFineTuner`（复用 Plan A 已经做好的分层学习率+渐进解冻结构，在此基础上叠加）：

```python
from losses.supcon_loss import SupConLoss

self.supcon_criterion = SupConLoss(temperature=0.1)
self.lambda_supcon = 0.3  # 初始值，后续做网格搜索

# 训练循环内（目标域 batch）：
neck_feat = model.get_neck_feature(images, skeletons)  # 需要在模型里暴露这个中间输出，final_norm之后
loss_supcon = self.supcon_criterion(neck_feat, binary_labels)

total_loss = (
    1.0 * loss_multi
    + 5.0 * loss_binary
    + self.lambda_supcon * loss_supcon
)
```

**注意**：只对目标域 batch 计算 SupCon loss，源域 batch 不计算（源域已收敛良好，且源域体量大，算 SupCon 会拖慢训练且无必要）。

## 退出条件：什么情况下该放弃继续调 SupCon，转向数据排查

满足以下任意一条，就不要继续在 SupCon 超参/训练策略上试错，改为人工抽样核查目标域数据：

1. `lambda_supcon` 从 0.1 加到 1.0，t-SNE 上两类簇的重叠程度没有随 lambda 增大而肉眼可见地改善
2. 概率直方图在 20 个 epoch 内始终没有出现双峰趋势（哪怕峰不明显，至少要看到往两端扩散的趋势）
3. Test set 指标相对 Plan A baseline 没有提升，甚至因为 SupCon loss 干扰了分类 loss 的收敛导致下降

此时下一步：从目标域训练集里，对"模型持续预测错误/低置信度"的样本（可以用 Plan A 的推理结果筛出来），抽取 20-30 张做人工复核，重点看：
- 这些样本的异常类型标注是否和源域 8 类定义的视觉表现一致（比如源域"手异常"主要是多指/缺指，目标域如果"手异常"标注的是别的视觉模式，模型学的是完全不同的东西）
- 目标域的成像风格（分辨率、光照、渲染方式）是否和源域差异大到骨架关键点检测（RTMPose）本身在目标域上就失准——如果骨架热力图输入本身质量差，会直接污染 cross-attention 注入的信息，这也会导致特征学不出判别性，且是 SupCon 无法解决的问题
